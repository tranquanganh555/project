# Cách tạo repository trên GitHub
- Repository là nơi lưu trữ tài nguyên dự án, kho chứa digital gồm 2 loại:
+ Local Repository
+ Remote Repository
- Ưu điểm sử dụng git:
+ Quản lý mã nguồn dễ dàng
+ Hồ sơ cá nhân
+ Học hỏi và cải thiện kỹ năng code
+ Kho tài nguyên đa dạng
## Các bước tạo:

 B1: Truy cập trang web github.com và đăng ký tài khoản của bạn
 
 B2: Nhấp vào nút “+” ở góc trên cùng bên phải của màn hình. 
 
 B3: Chọn “New repository”.
 
B4: Nhập tên cho repository của bạn và nhập mô tả cho repository của bạn.

B5: Chọn loại repository của bạn. Bạn có thể chọn giữa “Public” và “Private”.

B6: Nhấn Add a README file.

B7: Nhấp “Create repository”.
